fs-corruption-rca-collector
Python 3.8+ Non-Invasive Incident Response
View Repository

Non-invasive, read-only diagnostic telemetry collector for Linux filesystem corruption, I/O errors, and read-only remount incidents. Gathers live kernel ring buffers, mount state, dirty buffers, and storage controller indicators without modifying host state.

  • Strictly read-only & non-destructive
  • Parallel diagnostics execution
  • Built-in --selftest validator
  • Self-contained tarball bundle export
sudo python3 fs-corruption-rca-collector.py --out /tmp/rca-bundle.tar.gz
pmta-log-extract
Rust (Native) Python Fallback Streaming SIMD Decompression
View Repository

High-performance search and extraction utility for Port25 PowerMTA accounting CSV log archives. Streams through plain CSV, Gzip, Bzip2, and Zip archives with complex boolean criteria without extracting uncompressed files to disk.

  • Dual-stack engine: optimized Rust CLI + portable Python
  • Multi-format archive stream parsing (tar.gz, gz, bz2, zip)
  • Multi-field pattern matching (--orig, --rcpt, --type)
  • 100% verified test parity across implementations
./pmta-log-extract --orig "@example.com" --type d --path /var/log/pmta/ --out matches.csv
proxmox-inventory-extract
Rust (Native) Python Fallback Proxmox VE 7/8/9
View Repository

High-performance inventory exporter for Proxmox VE hypervisors and clusters. Extracts running and stopped QEMU VMs and LXC containers, correlates network addresses, storage backends (ZFS, LVM, Directory), OS metadata, and outputs normalized tabular data.

  • Complete cluster & standalone node inventory
  • API Token & password authentication methods
  • Guest IP, MAC, storage pool & size resolution
  • Asynchronous parallel fetching via Tokio
./proxmox-inventory-extract -e https://10.0.0.1:8006 -u root@pam -o inventory.csv
